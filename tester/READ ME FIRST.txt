INSTALL
-------
1. Right-click the zip and choose "Extract All...". Pick a place where the folder can stay,
   for example your Documents folder, and click "Extract". (Don't run it from inside the zip.)
2. In the folder that opens, double-click LaunchStage.exe. (Windows may show it as just "LaunchStage",
   with the LaunchStage icon.)
3. If Windows says "Windows protected your PC": click "More info", then "Run anyway".
   This shows because this early version isn't signed yet.
4. A short "Getting started" walkthrough shows you how to make your first profile.

Nothing else needs to be installed.


HELP
----
- Click "Help" at the top of the LaunchStage window (or press F1).
- Or open "LaunchStage guide.pdf" from this zip.


GOOD TO KNOW
------------
- LaunchStage starts with Windows and waits in the tray (by the clock). To stop that:
  Settings > General > untick "Start with Windows".
- Closing the LaunchStage window keeps it running in the tray. "Close App" exits completely.
- Have an Elgato Stream Deck (Stream Deck app 7.1 or newer)? Double-click the file in the
  "Stream Deck plugin" folder to add LaunchStage buttons.


FEEDBACK
--------
Tell Bones_84 what worked, what didn't, and anything that was confusing: on the LaunchStage GitHub page,
click "Issues", then "New issue". If something went wrong, please attach the log: Settings > Open log.
Issues are public, and the log lists the titles of your windows (like web page names), so look it over and
remove anything private before you post it.


REMOVE IT
---------
Please don't just delete the folder: LaunchStage would keep trying to start with Windows.
Instead, either:
- open LaunchStage, click Settings, and at the bottom click "Remove LaunchStage...", or
- double-click "Uninstall LaunchStage.cmd" (it's next to LaunchStage.exe).

It asks first, then removes everything LaunchStage added to your PC: the Start with Windows entry, Admin
support, its files and its folder. Untick "Also delete my profiles, settings and game history" if you want to
keep your profiles. If you use the Stream Deck plugin, remove it in the Stream Deck app (Preferences > Plugins).
