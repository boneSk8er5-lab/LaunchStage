# Browser windows and websites

Each browser window in a profile can open on its own websites, in its own window.

## Set a window's websites

1. Right-click the profile's card and click **Edit layout & apps...**.
2. Click the browser window in the list.
3. In the **Websites** box, type the sites, one per line. Each one opens as a tab. (`kick.com` is fine; LaunchStage adds `https://` for you.)
4. Click **Save profile**.

> Easier: open the browser on the site first, then click **Use the site it's showing now**. LaunchStage reads the address for you. When you add a browser window to a profile, it does this by itself.

Leave **Websites** empty and the browser shows whatever it normally shows when it starts.

## Private / incognito windows

1. Right-click the profile's card and click **Name, look & options...**.
2. Under **Open these browser windows as private / incognito**, tick the windows that should be private.
3. Click **Save profile**.

A private window only ever uses or closes private windows. Normal windows leave private ones alone.

## Which browsers work

Chrome, Brave, Edge, Firefox, Vivaldi, Opera and Opera GX, Chromium, Arc, Thorium, Zen, LibreWolf, Waterfox, Floorp and Mullvad Browser. Other browsers still open and get moved into place, just without the Websites box or private windows.
