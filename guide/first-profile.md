# Make your first profile

A profile is made from the windows you have open right now, so set things up the way you like them first.

1. Open every app you want in the profile.
2. Put each window where you want it and make it the size you want. Use all your monitors if you like.
3. In LaunchStage, click the dashed **New profile** card.
4. Type a **Name**, like `Stream`.
5. Pick an **Icon** and a **Color** for the card.
6. Under **Apps not in this profile**, choose what happens to everything else: **Leave them alone**, **Minimize them** or **Close them**.
7. In the list of windows, tick each window that belongs to this profile.
8. Click **Save profile**.

![The New profile window: name, icon, color, and the windows to tick](new-profile.png)

That's it. Your new profile shows up as a card in the LaunchStage window.

> Moved a window after you saved? No problem. You can change everything later. See [Move and resize windows](topic:move-windows).

## Good to know

- **Apps that are already open** are reused when the profile opens, just moved into place. LaunchStage only opens what's missing.
- **Apps that run as administrator** (some games, tools) need **Admin support**. Turn it on in **Settings**. See [Settings and look](topic:settings-and-look).
- **Browser windows** can open on their own websites. See [Browser windows and websites](topic:browsers).
